# Rules for this repo

This repo is public. Files under `files/claude/skills/` are copied to `~/.claude/skills/` and must stay free of
anything tied to a workplace or account: ticket ids, PR numbers, model ids, provider names (Bedrock, AWS SSO, etc.),
hostnames, and internal project names. State lessons as rules without the run they came from. Model panels live in
`~/.config/consilium/config`, never in the repo.
